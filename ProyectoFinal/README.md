# Proyecto final

Diagnóstico de inventario TI, construido paso a paso con la IA local.

## Contenido

| Fichero | Descripción |
|---|---|
| `datos/equipos.csv` | Inventario de equipos con algunos datos sucios |
| `main.py` | Programa principal, que usa los cinco módulos del paquete |
| `inventario_ti/__init__.py` | Paquete donde se guardan los módulos que genera la IA |
| `comprobar_paso1.py` a `comprobar_paso5.py` | Comprobadores de cada paso |

Los módulos `io_datos.py`, `analisis.py`, `modelos.py`, `reportes.py` y `graficos.py` los crea el alumno con la IA local. Los ficheros de `salida/` los genera `main.py`.
